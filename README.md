# PolygonZone

PolygonZone now lives in [Roboflow Workflows](https://roboflow.com/workflows). Draw polygon zones and lines and copy their coordinates in the Workflows editor: see [Draw Polygon Zones and Lines](https://docs.roboflow.com/workflows/build/draw-polygon-zones).

polygonzone.roboflow.com redirects to that page. The code for the old standalone web tool is in this repository's git history.
